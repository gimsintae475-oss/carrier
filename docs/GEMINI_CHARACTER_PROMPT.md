# GreenON 오리지널 캐릭터 이미지 생성 프롬프트

아래 프롬프트를 Gemini 이미지 생성 화면에 그대로 붙여 넣어 사용할 수 있습니다.

## 캐릭터 단독 이미지

```text
Carrier GreenON이라는 친환경 에어컨 미션 웹앱을 대표하는 완전히 새로운 오리지널 캐릭터 “보미(BOMI)”를 만들어줘.

보미는 시원한 바람을 의인화한 작고 둥근 요정이야. 몸은 파스텔 하늘색 물방울 모양이고, 양쪽 귀는 부드러운 선풍기 날개처럼 생긴 연두색 나뭇잎이야. 작은 잎사귀 꼬리, 짧고 말랑한 팔과 다리가 있고, 가슴에는 노란 데이지 꽃 배지가 있어. 점처럼 단순한 눈, 장난기 있는 비대칭 미소, 복숭아색 볼을 표현해줘. 한 손은 사용자를 향해 반갑게 흔들고, 다른 손에는 작은 흰 꽃을 들고 있어. 몸 주변에는 시원한 바람을 뜻하는 연한 하늘색 곡선 두 개를 넣어줘.

스타일은 굵고 단순한 네이비색 외곽선, 평면적인 파스텔 색, 살짝 손으로 그린 듯한 자연스러움이 있는 밝고 익살스러운 2D 애니메이션 캐릭터로 해줘. 특정 만화나 기존 캐릭터의 얼굴, 신체 비율, 의상, 포즈를 복제하지 말고 완전히 독창적인 실루엣과 정체성을 만들어줘.

색상은 하늘색, 민트색, 연두색, 따뜻한 노란색, 흰색을 중심으로 사용해줘. 캐릭터 전신이 잘리지 않게 중앙에 배치하고 주변 여백을 충분히 남겨줘. 텍스트, 로고, 워터마크는 넣지 마.
```

## 홈페이지 히어로 장면

```text
GreenON 오리지널 캐릭터 보미가 따뜻한 봄날의 꽃밭에서 사용자를 반기는 정사각형 2D 일러스트를 만들어줘.

보미의 디자인은 파스텔 하늘색 물방울 몸, 연두색 잎사귀 귀와 꼬리, 노란 데이지 배지, 장난기 있는 미소, 복숭아색 볼, 한 손을 흔드는 포즈로 일관되게 유지해줘. 배경은 맑고 연한 하늘색 하늘, 부드러운 흰 구름, 연두색 언덕, 작고 여백감 있게 배치된 흰색과 노란색 꽃밭으로 구성해줘. 보미 주변에는 시원한 바람을 뜻하는 하늘색 곡선을 넣어줘.

밝고 편안하며 귀여운 모바일 웹앱 일러스트 분위기로 만들고, 너무 화려하거나 유아적으로 보이지 않게 해줘. 굵고 단순한 네이비색 외곽선과 부드러운 파스텔 색을 사용해줘. 보미가 화면의 중심이 되도록 하고, 텍스트, 로고, 워터마크는 넣지 마. 기존 만화 캐릭터를 복제하거나 닮게 만들지 마.
```

현재 홈페이지에는 두 번째 프롬프트와 같은 구도의 보미 이미지가 `assets/bomi-hero.png`로 적용되어 있습니다.
